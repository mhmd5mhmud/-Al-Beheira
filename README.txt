مشروع: البحيرة عبر العصور — نسخة مدرسية مع سير مراجعة اقتراحات المعلومات

الملفات:
- index.html: صفحة الموقع والأقسام والنوافذ.
- style.css: التنسيق المتجاوب؛ تم الحفاظ على شكل الصفحة والقائمة والأقسام الموجودة.
- script.js: زر الإضافة، الفحص الآلي التجريبي، كشف التشابه، المراجعة والتعديل والموافقة والرفض.

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح index.html في المتصفح، أو ارفع الملفات إلى مستودع GitHub Pages.
3) اضغط زر «أضف معلومة» العائم على جانب الصفحة.
4) اختر القسم، واكتب العنوان والوصف. المصدر اختياري.
5) يجري فحص أولي للنص والارتباط المحتمل بمحافظة البحيرة والتكرار.
6) إذا اجتاز الفحص، يظهر في «مراجعة الاقتراحات». عدّل العنوان أو الوصف، واضغط «حفظ التعديل»، ثم قرر بنفسك «موافقة ونشر» أو «رفض».
7) لا تُضاف المعلومة إلى القسم إلا بعد الموافقة.

مهم جدًا بشأن الذكاء الاصطناعي:
هذه نسخة عرض مدرسية تستخدم قواعد JavaScript ومقارنة نصية محلية كفلترة أولية تجريبية؛ ليست نموذج ذكاء اصطناعي حقيقيًا ولا تتحقق من الحقائق تاريخيًا. تشغيل AI فعلي يحتاج إلى خدمة خلفية آمنة وواجهة API ومفتاح محفوظ على الخادم، ولا ينبغي وضع مفتاح API داخل ملفات HTML/JavaScript المنشورة للعامة. يمكن توصيلها لاحقًا بخادم دون تغيير تصميم الموقع.

مهم بشأن البيانات:
المقترحات والمعلومات الموافق عليها تُحفظ في localStorage على نفس المتصفح والجهاز فقط. لا تصل تلقائيًا إلى جهاز آخر ولا تعدّل ملفات GitHub Pages المنشورة. للحصول على مراجعة مركزية فعلية لكل الزوار يلزم خادم وقاعدة بيانات. هذه النسخة لا تحتوي على نظام دخول إداري.

المصدر اختياري كما طُلب. نتائج الفحص تقريبية وليست دليلًا على صحة المعلومة؛ راجعها قبل الموافقة النهائية.
