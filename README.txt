# البحيرة عبر العصور

موقع عربي RTL كبير مستوحى بصريًا من الصورة المرجعية التي أرسلها المستخدم، مع:
- تصميم زجاجي Glassmorphism وألوان أزرق/ذهبي.
- Hero section.
- تاريخ ونشأة المحافظة.
- خط زمني تفاعلي.
- مدن ومعالم.
- إحصائيات متحركة.
- معرض صور مع Lightbox.
- زر Dark Mode.
- قائمة موبايل Responsive.
- مصادر حكومية.
- تذييل باسم: AHMED OSAMA — DEVELOPED BY.

## التشغيل
افتح `index.html` مباشرة في Chrome أو Edge.

## ملاحظة الصور
الصور الحالية من Unsplash هي صور تمثيلية حتى يعمل التصميم فورًا. استبدل روابط الصور داخل `index.html` بصور حقيقية للبحيرة/رشيد/دمنهور عند توفرها.
